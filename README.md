# Xbox Game Pass Sales Dashboard 🎮📊

## Sobre o Projeto
Este projeto consiste em um dashboard analítico desenvolvido inteiramente em Microsoft Excel para monitorar e analisar as vendas de assinaturas do Xbox Game Pass. O objetivo é transformar dados brutos de transações em métricas acionáveis de negócio.

## Estrutura de Dados e KPIs
A análise foca na extração de insights a partir de uma base de dados de assinantes, gerando as seguintes métricas principais:
*   **Receita Total:** Faturamento consolidado de todas as assinaturas.
*   **Total de Assinantes:** Volume de usuários ativos na base.
*   **Ticket Médio:** Valor médio gasto por assinante.
*   **Performance por Plano:** Receita segmentada entre os planos Core, Standard e Ultimate.
*   **Taxa de Renovação:** Análise de conversão e retenção (Renovação Automática vs. Manual).

## Diferenciais Técnicos
*   **Design (Dark Theme):** Interface customizada focada em UX, utilizando a paleta de cores oficial do Xbox (#107C10) sobre fundo escuro (#1A1A1A).
*   **Tabelas Dinâmicas e Matrizes:** Cruzamento de dados de faturamento por tipo de assinatura e comportamento de renovação.
*   **Arquitetura Limpa:** Arquivo estruturado em camadas (Dashboard Visual, Cálculos de Back-end, Base de Dados Raw).

## Ferramentas Utilizadas
*   **Microsoft Excel** (Fórmulas, Tabelas Dinâmicas, Gráficos e Modelagem de Dashboard).

## Como Visualizar
1. Faça o download do arquivo `Projeto_Dashboard_Xbox_DarkTheme.xlsx`.
2. Abra no Microsoft Excel (recomendado para manter a integridade visual e funcionamento das tabelas dinâmicas).
3. Navegue pela aba "Dashboard - Visão Geral".
